Event Loop Demo (Call Stack → Microtask Queue → Task Queue)

Demonstrates the execution order of synchronous code, setTimeout (Macrotasks), Promise.then (Microtasks), and async / await. 

// Demo Code:
console.log('1. [Sync] Script start');

setTimeout(() => {
  console.log('2. [Task / Macrotask] setTimeout 1 (0ms)');
}, 0);

setTimeout(() => {
  console.log('3. [Task / Macrotask] setTimeout 2 (50ms)');
}, 50);

Promise.resolve().then(() => {
  console.log('4. [Microtask] Promise 1 resolved');
}).then(() => {
  console.log('5. [Microtask] Promise 2 chained');
});

async function asyncDemo() {
  console.log('6. [Sync inside async] asyncDemo before await');
  await null;
  console.log('7. [Microtask] asyncDemo after await');
}
asyncDemo();

console.log('8. [Sync] Script end');

  2. 6. [Sync inside async] asyncDemo before await
  3. 8. [Sync] Script end
  4. 4. [Microtask] Promise 1 resolved
  5. 7. [Microtask] asyncDemo after await
  6. 5. [Microtask] Promise 2 chained
  7. 2. [Task / Macrotask] setTimeout 1 (0ms)
  8. 3. [Task / Macrotask] setTimeout 2 (50ms)

Execution Flow Explained:

  1. Call Stack (Synchronous): Logs 1. Registers Timer 1 (0ms) and Timer 2 (50ms) with Browser Web APIs. Enqueues Promise 1 to the Microtask Queue. Calls asyncDemo(), logging 6 synchronously until await null yields and queues its continuation as a microtask. Finally logs 8. Call stack is now empty.
  2. Microtask Queue (Priority Drain): Before picking any macrotasks, the Event Loop drains all microtasks completely: logs 4 (which chains Promise 2 into the microtask queue), then resumes async function logging 7, then executes the chained promise logging 5.
  3. Task Queue (Macrotasks): With microtasks drained, the Event Loop dequeues the first ready macrotask: Timer 1 executes, logging 2. Later, Timer 2 (50ms) expires and is queued, then executed, logging 3.
